What's new in PRISM

Every update, in plain English. No marketing fluff.

v0.9
June 2026 Latest

Multi-file Upload & Marketing Dashboard

The biggest drop yet — combine multiple data sources and get your marketing KPIs automatically.

New
  • Multi-file Upload — combine Facebook, Google, Instagram exports in one query session
  • Auto Marketing Dashboard — 8 KPI cards (ROAS, CTR, CPC, CPA, Spend, Impressions, Clicks, Conversions) auto-detected on upload
  • Daily Spend trend chart and ROAS by Campaign bar chart, auto-rendered
  • PDF Report Generator — one-click white-label client report
  • KPI Excel Report export
  • AI query suggestions — autocomplete as you type
  • Smart Alerts — threshold rules with email + Slack notifications, alert history
  • Pinned Dashboard — pin charts from any query, persists across sessions
Improved
  • DB connection persistence — connections now survive backend restarts (saved to Supabase)
  • Password encryption — database passwords encrypted with private key before storage
  • Full design system — all inline styles replaced with CSS classes, empty states, hover effects
  • Dark / Light mode toggle with keyboard shortcut (Ctrl+/)
v0.8
May 2026 Beta

Query History, Saved Queries & Schema Explorer

Everything you need to work faster on repeat reporting tasks.

New
  • Query History — last 50 queries, re-run with one click
  • Saved Queries — star and tag frequently used queries
  • Query Templates — pre-built shortcuts for common marketing reports
  • Schema Explorer — browse tables, columns, types, and primary keys visually
  • Export to CSV, Excel, and PDF from any query result
  • Auto Charts — bar, line, pie, doughnut with X/Y axis selector
Improved
  • Login page — animated grid, glow orbs, password strength meter, shake animation on error
  • Keyboard shortcuts — Ctrl+Enter (run query), Ctrl+K (focus query bar)
v0.7
April 2026 Beta

Excel & CSV Upload + Multi-DB Support

No database? No problem. Drag and drop any spreadsheet and start asking questions.

New
  • Excel and CSV file upload with drag and drop
  • NL queries on uploaded files — Groq converts to pandas code
  • Column auto-detection and example question suggestions
  • Multi-database support — PostgreSQL, MySQL, MariaDB
  • Per-user isolated connections with RLS policy on Supabase
Fixed
  • Database connections no longer drop on backend restart
  • Query results now correctly handle NULL values
